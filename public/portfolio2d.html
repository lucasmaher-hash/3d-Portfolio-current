The Concept 1

A portfolio that reflects how I think — spatially. The 3D mode lets visitors walk through a studio environment where each project exists in physical space. The 2D mode is a clean, editorial layout for reading. Both share the same nav, the same content, and the same design language.

The Constraint 2

No frameworks. No React, no UI libraries — just vanilla JS, HTML, CSS, and Vite as a bundler. The constraint forced clarity: every animation, every interaction, and every layout decision was written by hand. The codebase stays readable and fast.

Process

2
Blender viewport
Blender 1

The 3D scene — a minimal studio with a Mac, a desk lamp, shelves, and framed work — was modeled and lit in Blender. Materials kept physically plausible for real-time rendering. Exported as a single compressed .glb loaded by Three.js at runtime.

Three.js browser view
Three.js 2

Custom first-person camera controller, HDR environment lighting, and click-to-open project overlays. The scene loads once and stays resident in memory as you navigate.

2D view — full page screenshot
2D Layout 3

The flat portfolio layer — built in HTML/CSS without a framework. Neumorphic surface design, OCR-A-BT display type, clamp()-based fluid spacing, and a bordered page-wrapper that collapses to full-bleed on mobile.

Mobile menu / joystick
Navigation 4

A shared nav bar (iframe-based) spans both modes. On mobile, a glassmorphic overlay menu replaces the desktop nav. A virtual joystick handles first-person movement in 3D.

Page slide transitions
Polish 5

Slide transitions between pages, scroll-hide nav behaviour, typewriter hero animation, and mobile landscape fullscreen — all in vanilla JS, zero libraries.
