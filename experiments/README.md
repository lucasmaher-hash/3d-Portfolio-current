# Experiments

Standalone prototypes. Each is a single self-contained HTML file with no external
assets — open it directly in a browser.

They used to live in `public/`, which meant Vite copied them into `dist/` and they
were published at e.g. `lucasmaher.com/blob_morph_bouncy.html`, despite nothing on
the site linking to them. Moving them here keeps them in version control without
shipping them.

- `blob_morph_bouncy.html` — bouncy blob morph study (the Unify hero blob's ancestor)
- `Questionmark_Button3d.html` — the 3D nav's "?" button, in isolation
